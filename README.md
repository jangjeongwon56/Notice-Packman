# SIB ERP 업데이트 소식 (설치 안내)

관리자가 홈페이지에서 로그인해 글을 쓰고, 고치고, 지우고, 사진(글당 3장)을 붙이는 페이지입니다.
거래처는 로그인 없이 `https://주소/` 에서 글만 봅니다. 관리자 화면은 `https://주소/admin` 입니다.

Cloudflare Pages(무료)에 올려서 씁니다. 비용이 들지 않는 한도 안에서 쓰도록 만들었습니다.

## 폴더 구성

| 폴더·파일 | 하는 일 |
|---|---|
| `public/index.html` | 거래처가 보는 화면 |
| `public/admin.html` | 관리자 화면(로그인 필요) |
| `public/_headers` | 보안 관련 응답 설정 |
| `functions/` | 로그인, 글 저장, 사진 올리기와 보기 (서버 쪽 기능) |
| `lib/` | 서버 기능이 함께 쓰는 코드 |

## 설치 순서 (처음 한 번만)

화면에 보이는 메뉴 이름은 Cloudflare가 바꿀 수 있어서 조금 다를 수 있습니다.

### 1. GitHub에 올리기
1. GitHub에 가입하고 새 저장소를 만듭니다. 이름은 자유입니다(예: `sib-notice`). 코드에는 비밀번호가 들어 있지 않아서 공개·비공개 모두 괜찮습니다.
2. 이 폴더의 모든 파일을 그 저장소에 올립니다. (`public`, `functions`, `lib` 폴더와 `package.json`, `README.md`)

### 2. Cloudflare Pages 만들기
1. Cloudflare에 가입하고 로그인합니다.
2. `Workers & Pages`에서 새로 만들기를 눌러 `Pages`를 고르고 `Git 연결`로 위 저장소를 선택합니다.
3. 설정은 아래처럼 합니다.
   - 프레임워크 사전 설정: `None`(없음)
   - 빌드 명령(Build command): 비워 둡니다
   - 빌드 출력 디렉터리(Build output directory): `public`
4. 저장하고 배포합니다. 이 단계에서는 아직 글 저장이 되지 않습니다. 아래 3~5번을 해야 합니다.

### 3. 저장소(KV) 만들기
1. Cloudflare 화면에서 KV 메뉴(`Storage & Databases` 아래)로 가서 새 네임스페이스를 만듭니다. 이름은 `sib-notice`로 합니다.

### 4. Pages 프로젝트에 연결하기
1. 만든 Pages 프로젝트의 `Settings > Bindings > Add > KV namespace`로 갑니다.
2. `Variable name`(변수 이름)에는 정확히 `NOTICE_KV` 라고 씁니다. 대소문자도 같아야 합니다.
3. `KV namespace`에서 3번에서 만든 `sib-notice`를 고르고 저장합니다.

### 5. 비밀번호와 보안 문구 넣기
`Settings > Variables and Secrets > Add`에서 아래 둘을 추가합니다. 둘 다 `Encrypt`(암호화)를 눌러 저장합니다.

| 이름 | 넣을 값 |
|---|---|
| `ADMIN_PASSWORD` | 관리자 비밀번호. 8자 이상, 남이 추측하기 어려운 것으로 정합니다. |
| `SESSION_SECRET` | 아무 영문·숫자나 32자 이상 길게 적습니다. 외울 필요 없습니다. |

### 6. 다시 배포하기
연결(4번)과 비밀값(5번)은 다시 배포해야 적용됩니다. `Deployments`에서 가장 최근 배포를 다시 배포(Retry)하세요.

### 7. 확인하기
1. `https://프로젝트이름.pages.dev` 를 열어 거래처 화면이 뜨는지 봅니다.
2. `https://프로젝트이름.pages.dev/admin` 에서 비밀번호로 로그인되는지 봅니다.
3. 테스트 글을 하나 올려 보고, 거래처 화면에 나오는지 확인한 뒤 지웁니다.

### 8. 회사 주소 연결하기 (선택)
1. Pages 프로젝트의 `Custom domains`에서 `notice.scm.packman.co.kr` 같은 주소를 추가합니다.
2. 화면에 나온 주소 값을 가비아 DNS 설정에 `CNAME` 으로 한 줄 추가합니다. (호스트: `notice.scm`, 값: Cloudflare가 알려 준 주소)
3. 연결 상태가 정상으로 바뀌면 `https://notice.scm.packman.co.kr` 로 엽니다.
4. 이 주소를 ERP(파워빌더) 버튼에 연결합니다.

## 사용 방법

- `/admin` 에서 비밀번호로 로그인합니다. 로그인은 12시간 동안 유지됩니다.
- **새 글 쓰기**: 날짜, 분류, 제목, 내용을 쓰고 `글 올리기`를 누르면 바로 저장됩니다. 내용에서 줄 맨 앞에 `- ` 를 붙이면 목록으로 보입니다.
- **사진**: 글 하나에 3장까지 붙일 수 있습니다. 올릴 때 자동으로 작게 줄여 줍니다. JPG, PNG 사진을 권합니다.
- **수정·삭제**: `올린 글`에서 `수정` 또는 `삭제`를 누릅니다. 삭제는 한 번 더 확인합니다.
- **문의처 등 변경**: 맨 아래 `페이지 정보`에서 바꿉니다.
- 저장한 내용이 거래처 화면에 나타나기까지 잠시(보통 1분 안팎) 걸릴 수 있습니다.

## 관리

- **비밀번호 바꾸기**: Cloudflare의 `ADMIN_PASSWORD` 값을 바꾸고 다시 배포합니다.
- **모든 로그인 끊기**: `SESSION_SECRET` 값을 바꾸고 다시 배포합니다.
- 비밀번호를 10번 연속 틀리면 그 접속자는 15분 동안 로그인할 수 없습니다.
- 글 데이터는 코드가 아니라 Cloudflare의 저장소(KV)에 있습니다. 코드를 다시 올려도 글은 지워지지 않습니다.

## 무료 한도 (공식 문서 기준)

- 서버 기능 호출: 하루 10만 건(Workers 호출과 합산). 거래처 한 명이 페이지를 열면 글 조회 1건과 사진 보기 최대 3건이 쓰입니다. 같은 사진은 브라우저가 저장해 두어 다시 열 때는 쓰이지 않습니다.
- 저장소(KV): 하루 읽기 10만 건, 쓰기 1,000건, 전체 1GB.
- 글 저장 1번에 쓰기 1건이 쓰이고, 사진 올리기 1장에도 1건이 쓰입니다.
- 무료 한도를 넘었을 때 어떻게 되는지는 확인하지 못했습니다. 하루 몇십 번 올리는 사용에서는 닿기 어려운 수준입니다.
